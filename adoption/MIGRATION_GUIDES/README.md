# Migration Guides

Migration Guides provide step‑by‑step instructions for teams adopting approved
standards. They translate governance intent into practical, actionable change.

A Migration Guide is required for every standard that affects more than one team.

---

## Purpose

- Provide clear, predictable steps for adopting a standard  
- Reduce ambiguity and friction during rollout  
- Ensure consistent implementation across teams  
- Identify risks, blockers, and dependencies early  

---

## What Belongs in This Directory

- Migration guides for individual standards  
- Before/after examples  
- Team‑specific migration notes (if applicable)  
- Known blockers and mitigation strategies  

---

## Principles

- Migration MUST be actionable and testable  
- Migration MUST align with the approved specification  
- Migration SHOULD minimize disruption  
- Migration SHOULD include measurable checkpoints  

---

## Steward Verification

The Steward ensures that:

- Migration guides are complete and accurate  
- They reflect the enforcement mechanisms  
- They support teams during the Adopt stage
