# Scaffolds

Scaffolds enforce standards at creation time by generating compliant files, folders,
and configurations automatically. They prevent drift by ensuring that new artifacts
start from a correct, standardized foundation.

Scaffolds are proactive enforcement.

---

## Purpose

- Ensure new components follow standards from the start  
- Reduce onboarding friction for new contributors  
- Provide consistent project structures across teams  
- Prevent violations before they occur  

---

## What Belongs in This Directory

- Code generators  
- Project templates  
- CLI scaffolding tools  
- Boilerplate files aligned with approved standards  
- Documentation for usage and integration  

---

## Principles

- Scaffolds MUST reflect the approved specification  
- Scaffolds MUST NOT introduce rules not approved through governance  
- Scaffolds SHOULD be easy to use and well‑documented  
- Scaffolds SHOULD reduce cognitive load for contributors  

---

## Steward Verification

The Steward validates that:

- Scaffolds match the approved standard  
- Generated artifacts are compliant  
- Documentation is complete and accessible
